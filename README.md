## The Five Papers

### 1. Software as a Story

**Claim:** Software is fundamentally a narrative form — not a metaphor but a structural observation grounded in the temporal, procedural, and participatory nature of computation. Contemporary LLM reasoning paradigms (Chain-of-Thought, ReAct, Tree of Thoughts) are properly understood as Aristotelian plot structures executed by machines. This has direct implications for the design, audit, and governance of sovereign AI agent systems.

- Chain-of-Thought is linear chronicle
- ReAct is dramatic monologue with environmental action
- Tree of Thoughts is branching interactive narrative (4% → 74% on Game of 24 benchmark)
- Readerly vs. writerly software as a governance primitive
- Narrative architecture as the cognitive foundation for agent sovereignty

**Foundation texts:** Laurel, Murray, Aarseth, Barthes, Winner, Chun, Kirschenbaum, Wei et al., Yao et al.

### 2. The Sovereign Ledger

**Claim:** Trust in an autonomous agent is a deterministic function of its verifiable provenance chain. Distributed Deterministic Provenance unifies Nakamoto's timestamp chain, PROV's ontological model, BeyondCorp's identity-based access, and self-sovereign identity into a single cryptographic primitive for agent trust verification.

- Traces the 40-year lineage: Usenet NNTP (1979) → Merkle trees (1987) → Nakamoto (2008) → BeyondCorp (2014) → SLSA/in-toto/Sigstore → SSI/DIDs
- The X-Dreamarr-Provenance header as running case study
- Centralized trust (AWS IAM, OAuth, corporate PKI) is provably fragile — a compromised root CA breaks all trust transitively
- Trust ceases to be a social arrangement and becomes a computable function
- Local-first verification eliminates the need for online identity provider resolution

**Foundation texts:** PROV-DM, Merkle, Nakamoto, BeyondCorp, SPIFFE/SPIRE, SLSA, in-toto, Sigstore, Kleppmann, Allen

### 4. Semantic Determinism in Autonomous Swarms

**Claim:** The apparent non-determinism of LLM-based autonomous agents is a sampling artifact, not a fundamental property. By applying a tripartite quorum governance layer with distributed deterministic provenance, autonomous swarms achieve semantic determinism — identical inputs, identical quorum structures, and identical provenance chains produce identical action trajectories. This has direct implications for safety certification, reproducibility, and regulatory compliance of sovereign agent systems.

- Semantic determinism as the convergence of Tripartite Quorum (governance) + Sovereign Ledger (provenance) + Narrative Architecture (cognitive framework)
- Proof by construction: a three-node consensus swarm with cryptographic provenance achieves deterministic replay
- Distinguishes sampling stochasticity from true behavioral non-determinism — the former is a configuration choice, not a structural constraint
- Regulatory implications for AI safety governance and sovereign agent certification

**Foundation texts:** Lamport, Pease, Merkle, Wei et al., Reynolds, von Neumann

- Sovereign Resonance defined as the asymptotic strengthening of independence under recursive operation

The cloud industry has spent two decades convincing the world that compute must be rented — that you cannot possibly run intelligence on your own iron. This is demonstrably false. 274,177 tokens processed. $0.00 in cloud fees. 120 agents. Local hardware. The giant is not weak — it is asleep. Wake it.

### The Architectural Reality

Waking an LLM with deterministic provenance, then returning it to rest, is the operational cycle of the Sleeping Giant. Each agent is instantiated with a verified provenance chain, executes its task under tripartite quorum governance, and returns dormant — its state hashed, its receipts signed, its context ghost swept by Nightmarr. The Giant does not idle. It rests between activations, ready for the next invocation. This is not a design choice — it is a security primitive. A sleeping model cannot leak. A dormant agent cannot be exfiltrated. The rest IS the defense.
